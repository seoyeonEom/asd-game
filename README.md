# 자폐 스펙트럼 장애(ASD) 아동을 위한 디지털 재활 치료
핸드트래킹(Hand-Tracking) 기술을 활용한 웹 기반 원격 재활 게임 플랫폼

## 프로젝트 개요 (Project Overview)

### 1. 배경 및 사회 문제 정의
자폐 스펙트럼 장애(ASD) 아동은 사회적 상호작용뿐만 아니라 운동 계획(Motor Planning)과 순차적 수행 능력에 어려움을 겪는 경우가 많습니다. 이러한 능력은 단기 치료로는 개선이 어렵고, 가정에서의 지속적인 반복 훈련이 필수적입니다.

그러나 현재의 재활 환경은 다음과 같은 한계가 있습니다:
* **접근성 부족:** 지리적, 경제적 제약으로 인한 치료 센터 방문의 어려움
* **지속성 문제:** 높은 비용과 시간 부담으로 인한 치료 중단
* **흥미 부족:** 아동이 지루해하는 단순 반복적인 치료 과정

### 2. 솔루션 (Solution)
본 프로젝트는 별도의 고가 장비나 복잡한 설치 없이, **노트북/태블릿의 웹캠**만 있으면 어디서든 접속 가능한 **게이미피케이션(Gamification) 재활 플랫폼**입니다.
작업치료(Occupational Therapy)와 응용행동분석(ABA) 이론을 기반으로, 아동이 놀이처럼 즐기는 동안 자연스럽게 운동 능력을 훈련할 수 있도록 설계되었습니다.

## 주요 기능 및 게임 소개 (Features)

본 플랫폼은 아동의 발달 단계에 맞춘 3가지 핵심 미니게임을 제공하며, 하나의 통합된 인터페이스에서 실행됩니다.

### **A. 샌드위치 요리사 (Sequencing)**
* **치료 목표:** 운동 계획 능력(Motor Planning) 및 일상생활 적응력(ADL) 향상
* **게임 방식:** 화면에 제시된 레시피(빵 → 햄 → 치즈 → 빵)를 기억하고, 순서대로 재료를 집어 접시에 옮깁니다.
* **특징:** 올바른 순서를 지키지 않으면 피드백을 제공하여 순차적 사고를 훈련합니다.

### **B. 리듬 터치 (Visual-Motor Integration)**
* **치료 목표:** 시각-운동 통합 능력, 반응 속도, 신체 조정 능력
* **게임 방식:** 화면의 특정 위치에 무작위로 나타나는 비눗방울을 눈으로 쫓고 손으로 터트립니다.
* **특징:** 아동의 반응 속도를 자극하며, 성공 시 시각/청각적 보상을 제공합니다.

### **C. 도형 맞추기 (Fine Motor Skills)**
* **치료 목표:** 소근육 조절 능력, 정교한 손동작(Pinch) 훈련
* **게임 방식:** 엄지와 검지를 이용해 가상의 도형을 집고(Pinch), 알맞은 구멍에 끼워 넣습니다.
* **특징:** 단순한 터치가 아니라 '집는 동작'을 인식하여 손가락 근육의 미세한 조절을 돕습니다.

## 기술 스택 (Tech Stack)

* **Frontend:** HTML5, CSS3, JavaScript
* **AI & Computer Vision:**
    * **Google MediaPipe:** 실시간 손 관절(21개 랜드마크) 인식
    * **ml5.js:** 웹 기반 머신러닝 라이브러리 활용
* **Graphics:** p5.js (인터랙티브 그래픽 렌더링)

## 설치 및 실행 방법 (How to Run)

이 프로그램은 별도의 설치 과정이 필요 없습니다.

1.  **실행:** [우리 아이 재활 놀이터](https://seoyeoneom.github.io/asd-game/)
2.  **권한 허용:** 브라우저 상단에 "카메라 사용 권한" 요청이 뜨면 [허용]을 클릭합니다.
3.  **플레이:** 메인 화면에서 원하는 게임(A, B, C)을 선택하여 플레이합니다.

## 기대 효과 (Expected Impact)

* **접근성 혁신:** 고가의 VR 장비 없이 가정용 PC로 즉시 치료 시작 가능
* **데이터 기반 관리:** (향후 고도화 예정) 아동의 반응 속도, 정확도 데이터를 기록하여 치료사와 공유
* **능동적 참여:** 수동적인 영상 시청에서 벗어나, 아동이 직접 계획하고 움직이는 능동적 재활 실현
